# TradeTrack Live Windows Screen Scanner v1.0.0

Native Windows version of the phone screen-sharing scanner.

## What it does
- No Chrome extension is required.
- No scanner token is required.
- Captures the selected Windows display directly.
- Start Screen Share once, then keep Quotex visible.
- Floating TT SCAN can be dragged anywhere.
- Tap TT SCAN around T-50…T-30.
- The app captures and verifies the running candle, holds a stable candidate, and reveals the NEXT-candle UP/DOWN signal near T-5…T-2.
- Right-click the floating TT SCAN button to reopen the main window.
- The app never clicks Quotex UP/DOWN and never places a trade.

## Build
The GitHub Actions workflow builds a portable Windows EXE with PyInstaller.
