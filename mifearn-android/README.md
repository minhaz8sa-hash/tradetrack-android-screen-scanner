# MIFearn Android Test Wrapper

Installable Android test wrapper for the production MIFearn Base44 application.

- Production URL: https://mifearn.com
- Base44 app ID: 6a3e603b8419aa87a150094b
- Test package: com.mifearn.mobile.debug
- Min Android: 7.0 (API 24)
- Target SDK: 35
- File/KYC upload: supported
- Camera capture from file inputs: supported
- Cookies/session storage: enabled
- Cleartext HTTP: blocked

This is a test APK wrapper. For Google Play production, use the official Base44 Mobile App AAB and confirm the final Play package/signing configuration before first upload.
